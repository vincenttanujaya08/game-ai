# AI Game

Aplikasi mandiri yang hanya berisi simulasi **Sitasi Bermasalah** dari NUSA Lab.

## Menjalankan

```bash
npm install
npm run dev
```

Buka <http://localhost:3000>. Game langsung tampil di halaman utama.

## Memeriksa

```bash
npm run check
npm run build
npm run test:e2e
```

Game berjalan dengan data skenario lokal dan respons AIRA deterministik, sehingga tidak membutuhkan API key atau layanan eksternal.
